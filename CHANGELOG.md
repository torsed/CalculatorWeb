# Changelog

Все заметные изменения проекта. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено

- `tests/core_deep.test.js`: глубокие unit-тесты solver, analysis, prog и
  linsystem — валидация аргументов, односторонние пределы, ошибки интегрирования,
  UTF-8 (суррогатные пары), поля IEEE-754, все коды ошибок систем уравнений.
- Пороги покрытия в `.c8rc.json` (78/74/70): деградация покрытия ядра теперь
  ломает прогон.

### Исправлено

- Конвертер: живые курсы валют молча не работали — `api.exchangerate.host` с
  2024 года требует `access_key`. Заменён на `open.er-api.com` (без ключа,
  CORS открыт, есть RUB/BYN/KZT/UAH); ответ дополнительно валидируется по
  `result: "success"`. Обновлены CSP (`index.html`) и белый список
  внешних хостов в `sw.js`.

- Решатель: символьный режим через собственный движок полиномов (любая степень),
  с фолбэком на численный поиск корней.
- Обратный расчёт формул: любое поле, кроме первого, можно оставить пустым —
  значение находится численно (бисекция).
- График: кнопка «Вписать Y» (автоподбор области) и экспорт таблицы значений в CSV.
- Матрицы: собственные значения (через характеристический многочлен) и решение
  системы `Ax=b`.
- Парсер: переменные `Ans` (последний результат) и `M` (память), синхронизируются
  с калькулятором.
- История: импорт вычислений из JSON (раньше был только экспорт).
- Вкладки: активный раздел запоминается в `localStorage`.
- Конвертер: пометка об офлайн-приближении курсов валют.
- Глобальный перехват необработанных ошибок и индикатор офлайн-режима.
- Service Worker: стратегия stale-while-revalidate для статических ресурсов.
- `apple-touch-icon`, доп. правила ESLint, `.gitattributes`.
- Типовая проверка `tsc --checkJs` (`tsconfig.json`, `types/globals.d.ts`) и
  покрытие `c8` (`npm run typecheck`, `npm run test:coverage`).
- Интернационализация (ru/en) для всего интерфейса и сообщений ядра: каталоги
  в `src/i18n/locales/*`, переключатель языка в шапке, выбор сохраняется в
  `localStorage` (`cw.lang`). Русский — язык по умолчанию.

#### Анализ, даты, системы, статистика, вероятность, числа, программирование

- Новая вкладка «Анализ»: производные (1-я и 2-я), касательная, определённый
  интеграл (Симпсон), пределы, суммы и произведения, поиск экстремумов;
  переключатель «градусы/радианы».
- Новая вкладка «Дата и время»: разница дат, прибавление дней/месяцев/лет,
  день недели и номер недели ISO, рабочие дни, возраст.
- Решатель: решение линейных систем 2×2, 3×3 и больше (автоопределение
  неизвестных).
- Статистика: корреляция Пирсона и Спирмена, линейная и полиномиальная
  регрессия (R²), t-тесты (одна и две выборки, Уэлч), доверительный интервал
  среднего, критерий χ².
- Вероятность: единый блок распределений и квантилей — нормальное, Стьюдента,
  χ², Фишера, показательное, равномерное, биномиальное, Пуассона, геометрическое,
  гипергеометрическое (плотность/функция распределения/квантиль).
- Матрицы: след, норма Фробениуса, степень, приведённый ступенчатый вид (RREF),
  LU- и QR-разложение.
- Теория чисел: функция Мёбиуса, π(n), число и сумма делителей, КТО (CRT),
  непрерывные дроби и подходящие дроби, параметры RSA.
- Программирование: IEEE-754 (hex и биты), Base64, URL-кодирование, CRC32,
  коды символов Unicode.
- Конвертер: новые категории — мощность, сила, момент силы, частота,
  освещённость, вязкость, типографика.

#### График и калькулятор

- График: режимы кривой `y=f(x)`, полярный `r=f(θ)` и параметрический
  `x(t), y(t)`; ползунки параметров `A`, `B`, `C`, `D`; интервал θ/t.
- Калькулятор: копирование результата, избранное в истории, панель пользовательских
  переменных и функций (`a = 5`, `f(x) = x^2`), окно горячих клавиш.

#### Инфраструктура

- CI на GitHub Actions (`.github/workflows/ci.yml`): lint, Prettier, `tsc`,
  модульные тесты и Playwright (e2e + axe) на каждый push и pull request.
- Публикация демо на GitHub Pages (`https://torsed.github.io/CalculatorWeb/`),
  значок статуса CI и ссылка на демо в README.
- `sw.js`: список кэшируемых файлов пополнен новыми модулями и переведён на
  пути относительно scope — офлайн-режим работает и в подпапке (GitHub Pages).

### Изменено

- `chem_balance.test.js` больше не завершает процесс при подключении через
  `require` из `tests/coverage.js`: из-за безусловного `process.exit` модульные
  тесты после него молча не попадали в отчёт c8 (покрытие занижалось).
- ESLint обновлён 8 → 10 (flat config, `eslint.config.js` вместо
  `.eslintrc.cjs`); c8 10 → 12, Playwright 1.63 → 1.64, axe-core 4.14.
- Тест конвертера курсов: офлайн-подсказка проверяется при заблокированном
  запросе, добавлен сценарий живых курсов через мок ответа API.
- Манифест: `purpose` иконки 512 разделён на отдельные записи `any` и
  `maskable` (совмещение обрезало иконку на части платформ).
- Убран бессмысленный для веб-приложения ключ `"main"` из package.json.
- Удалён mathjs (~650 КБ): его задачи решает собственный модуль `polynomial.js`.
- Вторая константа `cLog` переименована в `cLog10`; исправлены обратные
  тригонометрические функции (комплексные значения в радианах).
- `modInverse`/`modpow` переписаны на расширенный алгоритм Евклида.
- CSP: скрипты больше не требуют `'unsafe-inline'` (вынесены в файлы).
- CSP: стили больше не требуют `'unsafe-inline'` — единственный inline-стиль
  (`<noscript>`) вынесен в CSS-класс. Динамические стили через CSSOM под CSP
  не подпадают, поэтому их менять не потребовалось.
- Клавиатура калькулятора работает только на активной вкладке.
- Ampere: добавлен угол `α`; Химия: добавлены `T` и `Ea`.
- «Быт»: если заполнены все поля, результат пересчитывается по прямой формуле
  (раньше выдавалась подсказка «оставьте одно поле пустым»); подсказка об
  одном пустом поле показывается только когда пустых полей два и больше.

### Исправлено

- Изменение диапазона графика сразу после открытия вкладки не применялось.
- `_rangeRow` не валидировал все поля при вводе.
- Обратный своп единиц в конвертере использовал текст вместо значения.
- Пропущенные проверки на нечисловые результаты (`NaN`/`Infinity`) в формулах.
- «Быт»: обратный расчёт роста по BMI возвращал отрицательный корень
  (`h²` даёт два корня); поиск решения теперь начинается с положительных
  значений.
- «Быт» и «Программирование»: заголовок карточки показывал название бренда
  вместо имени вкладки; убран лишний пробел после результата без единицы.
- «Быт»: обратный расчёт теперь показывает единицу измерения ответа
  (`m = 67.375 кг`, `V = 50 км/ч`); подписи формул «Чаевые» и «Процентное
  изменение» приведены в соответствие с именами полей (`T = S·p / 100`,
  `Δ% = (b − a) / a·100`); уточнено сообщение про одно пустое поле.
