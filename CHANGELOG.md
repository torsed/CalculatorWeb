# Changelog

Все заметные изменения проекта. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено

- Решатель: символьный режим через собственный движок полиномов (любая степень),
  с фолбэком на численный поиск корней.
- Обратный расчёт формул: любое поле, кроме первого, можно оставить пустым —
  значение находится численно (бисекция).
- График: кнопка «Вписать Y» (автоподбор области) и экспорт таблицы значений в CSV.
- Матрицы: собственные значения (через характеристический многочлен) и решение
  системы `Ax=b`.
- Парсер: переменные `Ans` (последний результат) и `M` (память), синхронизируются
  с калькулятором.
- История: импорт вычислений из JSON (раньше был только экспорт).
- Вкладки: активный раздел запоминается в `localStorage`.
- Конвертер: пометка об офлайн-приближении курсов валют.
- Глобальный перехват необработанных ошибок и индикатор офлайн-режима.
- Service Worker: стратегия stale-while-revalidate для статических ресурсов.
- `apple-touch-icon`, доп. правила ESLint, `.gitattributes`.
- Типовая проверка `tsc --checkJs` (`tsconfig.json`, `types/globals.d.ts`) и
  покрытие `c8` (`npm run typecheck`, `npm run test:coverage`).
- Интернационализация (ru/en) для всего интерфейса и сообщений ядра: каталоги
  в `src/i18n/locales/*`, переключатель языка в шапке, выбор сохраняется в
  `localStorage` (`cw.lang`). Русский — язык по умолчанию.

### Изменено

- Удалён mathjs (~650 КБ): его задачи решает собственный модуль `polynomial.js`.
- Вторая константа `cLog` переименована в `cLog10`; исправлены обратные
  тригонометрические функции (комплексные значения в радианах).
- `modInverse`/`modpow` переписаны на расширенный алгоритм Евклида.
- CSP: скрипты больше не требуют `'unsafe-inline'` (вынесены в файлы).
- CSP: стили больше не требуют `'unsafe-inline'` — единственный inline-стиль
  (`<noscript>`) вынесен в CSS-класс. Динамические стили через CSSOM под CSP
  не подпадают, поэтому их менять не потребовалось.
- Клавиатура калькулятора работает только на активной вкладке.
- Ampere: добавлен угол `α`; Химия: добавлены `T` и `Ea`.

### Исправлено

- Изменение диапазона графика сразу после открытия вкладки не применялось.
- `_rangeRow` не валидировал все поля при вводе.
- Обратный своп единиц в конвертере использовал текст вместо значения.
- Пропущенные проверки на нечисловые результаты (`NaN`/`Infinity`) в формулах.
